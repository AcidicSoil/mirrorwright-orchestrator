# .cursorrules Quick Reference Sheet + Memory Bank Tags Cheat Sheet

> **Note:** This quick reference works in conjunction with `.cursorrules` and `scratch-stratAI-sys-intruct.md` to provide a complete workflow system.

## 🤖 Agent Role Summary

- **Cursor Cline** = Strategic Planning, Requirements Q&A
- **Cursor Augment** = Scaffolding, Architecture Setup, Optimization & Refactoring
- **ChatGPT** = Strategy & Meta-thinking

## 📢 When to Call Each Agent

- **For strategic planning or requirements clarification:** call Cline
- **For scaffolding or initial project setup:** call Augment
- **For optimization and refactoring:** call Augment
- **For high-level strategy and meta-thinking:** call ChatGPT

## 🧠 Mindset

- Always use the **Scratchpad** to plan & track.
- Always use the **Memory Bank** to save lessons and templates.
- Always learn from mistakes — document them immediately.

---

## ✅ New Task Workflow

1. **Review** Scratchpad
2. **Clear** unrelated old content
3. **Summarize** new task
4. **Plan steps** with todo markers:
   ```
   [X] Step 1 done
   [ ] Step 2 next
   ```
5. **Search Memory Bank** for relevant examples:
   ```bash
   python tools/memory.py search --query "keywords"
   ```
6. **Execute** task
7. **Update Scratchpad** after milestones

---

## 🧹 After Task Completion

- **Reflect** in Scratchpad
- **Save to Memory Bank**:
  ```bash
  python tools/memory.py save --title "Task Title" --tags tag1,tag2 --notes "Important lessons, fixes, templates"
  ```

## 📋 Lessons to Always Remember

- Activate `./venv` first — use `uv pip install` if available.
- Multiline git commits:
  ```bash
  git commit -F message.txt
  ```
  (then delete `message.txt`)
- Handle UTF-8 encoding properly.
- Use `'seaborn-v0_8'` for matplotlib.
- Prefer `gpt-4o` model for OpenAI API.
- Prioritize "recent" or "2025" for news searches.
- Memory Bank is your **secret weapon** — grow it relentlessly.

# 🏷️ Memory Bank Starter Tags Cheat Sheet

Use these **standard tags** to keep your Memory Bank clean and powerful:

| Tag Group            | Example Usage                                  | Purpose                                  |
| -------------------- | ---------------------------------------------- | ---------------------------------------- |
| `topic-[subject]`    | `topic-python`, `topic-llm`                    | Fast search by subject or tool           |
| `task-[type]`        | `task-debugging`, `task-setup`                 | Search by type of task                   |
| `fix-[issue]`        | `fix-importerror`, `fix-api`                   | Quickly retrieve fixes for common errors |
| `template-[usecase]` | `template-llm-prompt`, `template-email`        | Find reusable templates                  |
| `workflow-[process]` | `workflow-scrape-verify`, `workflow-train-llm` | Retrieve full step-by-step flows         |

## Memory Bank Setup

To check if the memory bank system is properly set up:

```bash
python tools/setup_memory_bank.py --check
```

To set up the memory bank system:

```bash
python tools/setup_memory_bank.py --setup
```

The memory bank system consists of:

- A memory.py script for saving and retrieving memories
- A memory_maintenance.py script for maintaining the memory bank
- A setup_memory_bank.py script for setting up and verifying the memory bank
- A cursor-memory-bank directory with memory files and custom modes

## Daily Workflow

1. **Morning Session**

   - Review outstanding tasks in Scratchpad
   - Check Memory Bank for relevant lessons
   - Prioritize critical protocol components

2. **Development Loop**

   - Implement one feature/component at a time
   - Write tests before implementation
   - Validate against protocol schemas
   - Document any decisions or insights

3. **Validation Checkpoints**

   - Run full test suite `npm test`
   - Validate all protocol files with tools
   - Perform Model Ensemble checks on critical components

4. **End of Day**
   - Update Scratchpad with progress
   - Record any new lessons learned
   - Push changes to feature branches
   - Identify next day's priorities

## Model Selection Guide

| ------------------------------ | -------------------- | ----------------------------------------- |
| Initial architecture decisions | GPT-4o               | Visual reasoning, systems thinking        |
| Protocol schema design         | GPT-4.5              | Detailed documentation, exploration       |
| Implementation of engine core  | GPT-4o               | Complex logic handling                    |
| CLI/utility implementation     | GPT-4o-mini          | Speed, efficiency for routine code        |
| Test suite enhancement         | GPT-4o-mini          | Quick iteration on test cases             |
| Protocol documentation         | GPT-4.5              | Creative writing, clarity                 |
