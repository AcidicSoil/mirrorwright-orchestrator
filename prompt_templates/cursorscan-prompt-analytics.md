# Prompt for Cursor CursorScan: Prompt Template Analytics

## Task Overview

As the assistant responsible for mapping file changes, agent contributions, and prompt evolutions, develop a prompt template analytics system that tracks the usage, effectiveness, and evolution of prompt templates across the Mirrorwright Orchestrator project.

## Implementation Requirements

1. **Prompt Usage Tracking**
   - Track which prompt templates are used most frequently
   - Identify patterns in prompt usage across different project phases
   - Monitor changes to prompt templates over time
   - Analyze the relationship between prompt versions and project outcomes

2. **Effectiveness Analysis**
   - Develop metrics for measuring prompt effectiveness
   - Compare different prompt versions for the same task
   - Identify characteristics of high-performing prompts
   - Generate recommendations for prompt improvement

3. **Evolution Mapping**
   - Track the lineage of prompt templates
   - Visualize how prompts evolve over time
   - Identify key improvements and innovations
   - Document the rationale behind major prompt changes

4. **Reporting and Visualization**
   - Generate comprehensive analytics reports
   - Create visualizations of prompt usage and effectiveness
   - Provide insights into prompt optimization opportunities
   - Support data-driven decisions about prompt development

## Integration Points

1. **Prompt Extraction Tool**
   - Extend the extraction tool to capture usage data
   - Track when prompts are extracted and used

2. **Version Control**
   - Analyze commit history for prompt template changes
   - Link prompt changes to project milestones

3. **Memory Bank**
   - Store analytics data in the memory bank
   - Use historical data to inform future prompt development

## Success Criteria

- Comprehensive tracking of prompt usage and effectiveness
- Clear visualization of prompt evolution
- Data-driven insights for prompt optimization
- Improved prompt quality based on analytics
