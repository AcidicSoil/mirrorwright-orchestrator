# Memory and Context Management

This directory contains documents that describe the memory management and context preservation mechanisms used in the Mirrorwright Orchestrator project.

## Contents

- **[memory-bank-config.md](./memory-bank-config.md)**: Configuration for the memory bank integration
- **[memory-bank-tags.md](./memory-bank-tags.md)**: Tag schema for memory bank entries

## Purpose

These documents provide information about how memory and context are managed in the Mirrorwright Orchestrator project. They explain the structure of the memory bank, how to save and retrieve memories, and how to use tags effectively.

## When to Reference

Reference these documents when:
- Working with the memory bank
- Creating or retrieving memories
- Designing tag schemas for new memory types
- Implementing context preservation mechanisms
