# Template Standards and Validation

This directory contains documents that define the standards and validation requirements for templates used in the Mirrorwright Orchestrator project.

## Contents

- **[prompt-frontmatter-standard.md](./prompt-frontmatter-standard.md)**: Standard for prompt template frontmatter
- **[validation-results.md](./validation-results.md)**: Current validation status of prompt templates

## Purpose

These documents provide information about the standards and validation requirements for templates used in the Mirrorwright Orchestrator project. They explain how to create valid templates, how to validate them, and how to ensure consistency across all templates.

## When to Reference

Reference these documents when:
- Creating new templates
- Validating existing templates
- Understanding the frontmatter requirements
- Implementing template validation logic
