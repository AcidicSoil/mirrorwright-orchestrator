# Schema and Protocol Documentation

This directory contains documents that define and explain the schemas and protocols used in the Mirrorwright Orchestrator project.

## Contents

- **[example-protocol-structure.md](./example-protocol-structure.md)**: Examples of protocol files, modes, rituals, and templates
- **[protocol-schema.md](./protocol-schema.md)**: The formal schema definition for protocols
- **[mode-schema.md](./mode-schema.md)**: The schema definition for mode configurations

## Purpose

These documents provide the technical specifications for the Mirrorwright Orchestrator's protocol system. They define the structure and validation rules for protocols, modes, and rituals.

## When to Reference

Reference these documents when:
- Creating new protocol definitions
- Designing mode or ritual configurations
- Implementing validation logic
- Understanding the relationships between different protocol components
