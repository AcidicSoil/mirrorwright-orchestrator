# Assistant-Specific Documentation

This directory contains documents that describe the roles, responsibilities, and configurations of the assistants used in the Mirrorwright Orchestrator project.

## Contents

- **[prompt-templates-readme.md](./prompt-templates-readme.md)**: Overview of prompt templates and assistant roles
- **[all-assistant-prompts.md](./all-assistant-prompts.md)**: Current prompts for all assistants

## Purpose

These documents provide information about the different assistants used in the Mirrorwright Orchestrator project. They explain the roles and responsibilities of each assistant, when to use them, and how they interact with each other.

## When to Reference

Reference these documents when:
- Understanding the role of a specific assistant
- Creating new prompts for assistants
- Planning multi-agent workflows
- Determining which assistant to use for a specific task
