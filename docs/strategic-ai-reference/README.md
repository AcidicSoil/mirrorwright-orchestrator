# Strategic AI Reference Documentation

This directory contains a curated collection of reference documents for the Mirrorwright Orchestrator project, organized to provide comprehensive context for strategic AI assistants.

## Purpose

These documents serve as a knowledge base for strategic AI assistants, providing them with the necessary context to understand the project's architecture, protocols, tools, and workflows. By having access to these documents, strategic AI can provide more relevant and accurate assistance as the project evolves.

## Directory Structure

- **[core/](./core/)**: Core project structure and architecture documents
- **[schemas/](./schemas/)**: Schema and protocol documentation
- **[tools/](./tools/)**: Tool and implementation documentation
- **[assistants/](./assistants/)**: Assistant-specific documentation
- **[memory/](./memory/)**: Memory and context management
- **[templates/](./templates/)**: Template standards and validation
- **[conversations/](./conversations/)**: Strategic conversation templates

## How to Use

1. **For Strategic Planning**: Start with the core/ directory to understand the project's overall structure and architecture.
2. **For Protocol Development**: Refer to the schemas/ directory for schema definitions and protocol examples.
3. **For Tool Development**: Check the tools/ directory for documentation on existing tools and implementation patterns.
4. **For Assistant Configuration**: Use the assistants/ directory to understand the roles and responsibilities of different assistants.
5. **For Memory Management**: Explore the memory/ directory for information on memory bank structure and tag schemas.
6. **For Template Development**: Review the templates/ directory for standards and validation requirements.
7. **For Strategic Conversations**: Use the conversations/ directory for templates and examples of strategic AI conversations.

## Updating This Documentation

When making significant changes to the project, consider updating the relevant documents in this directory to ensure strategic AI assistants have the most current information. Follow these guidelines:

1. Maintain the existing directory structure
2. Update documents rather than removing them
3. Add new documents as needed, following the established patterns
4. Update the README.md files to reflect any changes
